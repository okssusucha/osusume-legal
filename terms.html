第2条（本アプリの概要）

本アプリは、個人が開発したローカル動作のWebアプリケーションです。主な機能は次のとおりです。

  • 楽天の商品検索API（以下「楽天API」）を通じて、実在する商品の情報（商品名・価格・画像・アフィリエイトリンク）を取得します。
  • 取得した商品情報をもとに、TikTok向けの縦型（9:16）「商品ランキング紹介動画」を利用者のコンピュータ上で自動生成します。
  • 利用者がブラウザのUI（http://127.0.0.1:8799）上で動画をプレビュー・承認します。
  • 承認された動画を、TikTok Content Posting API の video.upload スコープを用いて、利用者本人のTikTokアカウントの「下書き（inbox）」へアップロードします。
本アプリは、TikTok上での最終的な公開操作を一切行いません。アップロードされた動画はTikTokの下書き（inbox）に保存されるのみであり、公開はすべて利用者がTikTokアプリ内で手動で行います。本アプリは video.publish（API経由の直接公開）スコープを使用しません。

第3条（動作環境とローカル動作）

  • 本アプリは、利用者自身のコンピュータ（Mac）上のローカルホスト（localhost / http://127.0.0.1:8799）で動作します。
  • 運営者は商用のホスティングサーバーやクラウドサービスを提供しておらず、本アプリのデータを保持する運営者側のサーバーは存在しません。
  • 本アプリの導入・起動・維持に必要な環境（端末、OS、ネットワーク等）は、利用者の責任と費用で用意するものとします。

第4条（TikTokおよび楽天との連携）

本アプリは、その機能を実現するために次の外部サービスと通信します。

  • TikTok：Login Kit（OAuthによる認可）および Content Posting API を利用します。使用するスコープは video.upload のみです。通信先は TikTok 公式API（open.tiktokapis.com 等）です。
  • 楽天：楽天の商品検索APIを利用して商品情報を取得します。

本アプリは上記以外の外部サーバーへデータを送信しません。データの取扱いの詳細はプライバシーポリシーをご確認ください。

  • 利用者は、当該トークンファイルを削除することで、いつでもTikTokとの連携を解除できます。連携解除後は再度の認可が必要となります。

第6条（動画の生成・承認・アップロード）

  • 本アプリが生成する動画は、楽天APIから取得した実在の商品情報に基づきます。
  • 商品画像は無改変で使用します。
  • 動画は、利用者がブラウザUI上でプレビューし承認した場合にのみ、TikTokの下書き（inbox）へアップロードされます。利用者の承認なくアップロードが行われることはありません。

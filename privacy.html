3. 取得・取扱いするデータ

本アプリが取扱うデータは、本アプリの機能を実現するために必要な範囲に限られます。いずれも利用者のコンピュータ上で処理・保存され、運営者がこれらを受領・閲覧することはありません。

データの種類内容取得元 / 生成元
TikTok認証トークン OAuthアクセストークンおよびリフレッシュトークン TikTokのLogin Kit（利用者本人の認可）

本アプリは、利用者の氏名・住所・電話番号・決済情報といった個人情報を独自に収集することはありません。

4. データの保存場所（ローカル動作）

本アプリは利用者自身のコンピュータ（Mac）上のローカルホスト（http://127.0.0.1:8799）で動作します。運営者は商用ホスティングを行っておらず、データを保持する運営者側のサーバーは存在しません。
  • TikTokのアクセストークンおよびリフレッシュトークンは、利用者のローカルファイル data/tiktok_token.json にのみ保存されます。
  • 商品情報、生成された動画ファイル、設定データも、すべて利用者のコンピュータ上にのみ保存されます。
  • これらのデータが運営者または第三者のサーバーへ送信・複製・保管されることはありません。

5. データの利用目的

本アプリは、取扱うデータを次の目的にのみ利用します。

  • 楽天APIから取得した商品情報をもとに、TikTok向けの紹介動画を生成するため。
  • 利用者がプレビュー・承認した動画を、TikTok Content Posting API を通じて利用者本人のTikTok「下書き（inbox）」へアップロードするため。
  • TikTok認証トークンは、上記アップロードのためのAPI認証にのみ利用します。

上記以外の目的（広告配信、プロファイリング、行動解析、第三者への提供等）には一切利用しません。

6. 通信先（TikTok / 楽天API）

本アプリが外部と通信するのは、以下の公式APIに対してのみです。

  • TikTok公式API（open.tiktokapis.com 等）：認可および動画の下書きアップロードのため。
  • 楽天API：商品情報の取得のため。

上記以外の外部サーバー（運営者のサーバーを含む）へデータを送信することはありません。

7. TikTokから取得する情報とスコープ

本アプリは TikTok の Login Kit（OAuth認可）および Content Posting API を利用します。要求するスコープは次のとおりです。

  • video.upload：利用者本人のTikTokアカウントへ動画を下書き（inbox）として共有するためのスコープ。これが本アプリが要求する唯一のスコープです。
本アプリは video.publish（API経由での直接公開）スコープを使用しません。アップロードされた動画はTikTokの下書きに保存されるのみで、最終的な公開はすべて利用者がTikTokアプリ内で手動で行います。本アプリがTikTok上のコンテンツを利用者に代わって公開することはありません。

本アプリが取得・保存するTikTok由来の情報は、上記スコープに伴う認証トークンに限られます。本アプリが利用者のTikTok上の個人プロフィールやフォロワー情報等を収集・保管することはありません。

8. 第三者提供・外部送信・解析の不実施

  • 本アプリは、取扱ういかなるデータも第三者へ提供・販売・貸与しません。
  • 運営者のサーバーを含む外部サーバーへデータを送信しません（第6条に定めるTikTok・楽天の公式APIとの通信を除く）。
  • アクセス解析・行動トラッキング・広告目的の利用は一切行いません。
  • 本アプリにはアナリティクスSDKや外部トラッカーは組み込まれていません。

9. データの保持期間

  • TikTok認証トークン、商品情報、生成動画、設定データは、利用者のコンピュータ上に保存され、利用者が削除するまで保持されます。
  • 運営者はこれらのデータを保持しないため、運営者側での保持期間という概念は存在しません。
  • データの削除・保持は、すべて利用者の管理下にあります。

10. 連携解除・データ削除の方法

利用者は、いつでも次の方法でTikTokとの連携を解除し、データを削除できます。

  • 連携解除：ローカルのトークンファイル data/tiktok_token.json を削除してください。これにより本アプリはTikTokへアクセスできなくなり、連携が解除されます。
  • 動画・商品データの削除：本アプリが生成・保存したファイルを、利用者のコンピュータ上から削除してください。
  • TikTok側での取消：TikTokアプリまたはTikTokの設定画面から、本アプリへ付与した認可を取り消すこともできます。

連携解除後に本アプリを再度利用する場合は、改めてTikTokの認可（OAuth）が必要です。

11. セキュリティ

  • 本アプリはローカルホスト（127.0.0.1）でのみ動作するよう設計されており、外部ネットワークからの直接アクセスを想定していません。
  • 認証トークンを含むデータは利用者のコンピュータ上に保存されるため、当該コンピュータおよびトークンファイルの安全管理は利用者の責任で行ってください。
  • 運営者はデータを保持しないため、運営者側でのデータ漏えいリスクは構造的に存在しません。

12. Cookie・トラッキング

本アプリは、広告・解析目的のCookieやトラッキング技術を使用しません。ブラウザUIの動作に必要な範囲でローカルの状態保持を行う場合がありますが、これらが外部へ送信されることはありません。
